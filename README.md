# 🎮 Rock Paper Scissors

- A simple Rock-Paper-Scissors web game built with HTML, CSS, and JavaScript — play against the computer and see who wins! 🪨📄✂️

## 🧠 Gameplay Logic

When a player clicks on one of the options:

- ✔️ The computer randomly selects Rock, Paper, or Scissors.
- ✔️ The game compares the user choice vs. the computer choice.
- ✔️ Scores are updated, and the result message shows the outcome — win, lose, or tie.

This is implemented purely with vanilla JS (no frameworks). 🎯

# 🗂️ Files in This Repo

| File         | Description                                     |
| ------------ | ----------------------------------------------- |
| `index.html` | The basic UI and game layout                    |
| `style.css`  | Simple styling for game visuals                 |
| `app.js`     | Game logic and event handlers                   |
| `image/`     | Game asset images (Rock, Paper, Scissors icons) |


## 💡 Features

- ✨ Responsive, intuitive UI
- 🎲 Randomized computer moves
- 📊 Live score updates
- 🚦 Clear result messages


## 🛠️ How It Works

The game logic (in app.js) does the following:
* Stores user and computer scores
* Listens for click events on the choice icons
* Generates a random computer choice
* Determines the winner or whether it's a draw
* Updates the DOM with the result and new scores
*You can explore the logic inside app.js — it’s clean and beginner-friendly! 🎉
